# 示例计划：个人主页三页小站

## 背景与目标

做一个纯静态个人主页小站，共三个页面，风格简洁现代，中文排版，无需后端与构建工具，直接双击 index.html 即可浏览。

## 页面清单

1. `index.html` —— 首页：个人简介、技能标签、最近动态三块内容，顶部导航可跳转另外两页。
2. `projects.html` —— 项目页：至少 3 个项目卡片，每张卡片含标题、一句话简介、技术栈标签。
3. `about.html` —— 关于页：联系方式的静态展示（邮箱、GitHub 用户名占位即可）。

## 技术要求

- 样式统一写在 `styles.css`，三页共用；禁止内联样式。
- 响应式：窗口宽度 800px 以下时导航折叠为上下排列。
- 配色：浅色主题，主色调用蓝绿色系，正文用深灰而非纯黑。
- 所有图片用占位符或纯 CSS 图形，不引用外链资源。

## 验收标准

- 三页互链可达，导航高亮当前页。
- 无控制台报错，无外网请求。
- 代码缩进整齐、注释适度，.html 文件均声明 UTF-8 编码。
