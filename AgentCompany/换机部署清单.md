# 换机部署清单 · 小公司 Agent 指挥中心 v1.1.1

按顺序执行，每条都附"如何验证成功"。⚠️ 全文不含任何真实 API key——需要填 key 的地方一律用 `<你的key>` 占位。

## 0. 前置

| 条目 | 要求 | 验证 |
|------|------|------|
| 操作系统 | Windows 10/11 x64 | `systeminfo \| findstr /B "OS"` |

## 1. 装 Node.js LTS

```bat
winget install OpenJS.NodeJS.LTS
```

（或官网 https://nodejs.org 下载 LTS 安装包）

**验证**：新开终端执行 `node -v` 与 `npm -v`，均输出版本号即成功。

## 2. npm 安装三个员工 CLI

以官方实际包名为准（本机实测可用组合）：

```bat
npm i -g @anthropic-ai/claude-code @opencode/cli @charmland/crush
```

**验证**：`where claude`、`where opencode`、`where crush` 三条都能列出路径（通常是 `C:\Program Files\nodejs\...` 或 nvm 目录下的 .cmd）。注意 PATH 是程序启动时的快照——装完后**再**启动本程序。

## 3. 三个员工分别配置智谱鉴权

三者都走智谱（BigModel / 智谱 Coding Plan / z.ai）的 GLM 系模型，鉴权各自独立：

### 3.1 claude（含 CEO）→ ANTHROPIC 兼容端点

编辑 `%USERPROFILE%\.claude\settings.json`（没有则新建），写入：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://open.bigmodel.cn/api/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "<你的key>"
  }
}
```

**验证**：`claude -p "只回两个字：收到"` 输出「收到」即成功（key 无效会报 401/鉴权错误）。

### 3.2 opencode → 登录智谱 Coding Plan

```bat
opencode auth login
```

按交互选择智谱 Coding Plan（GLM Coding Plan）完成登录。

**验证**：`opencode run "只回两个字：收到"` 输出「收到」即成功。

### 3.3 crush → 配置 zai（智谱）provider

首次运行 `crush` 进交互界面，选择/配置 zai provider 并填入 `<你的key>`（凭据存于 `%USERPROFILE%\.crush\`）。

**验证**：`crush models` 列表中能搜到 zai 系模型（`crush models | findstr zai`）即成功。

## 4. 拷贝程序

整个 `publish\` 文件夹原样拷到目标机任意路径（如 `D:\AgentCompanyPortable\`），须保持内部结构：

```
AgentCompanyPortable\
  AgentCompany.exe            ← 主程序（自包含单文件，免装 .NET）
  McpBridge\AgentCompany.McpBridge.exe   ← 公司工具与审批门
  agentcompany.cmd + cli\agentcompany.exe ← 终端模式（v1.1 新增，CEO 对话）
  使用手册.md / 换机部署清单.md
```

工作区默认建在 **exe 旁的 `workspace\`**（整个文件夹拷到哪、工作区跟到哪）；状态库在 `%APPDATA%\AgentCompany\state.db`——程序目录可随意搬，数据不丢。**提示词外置目录** `%APPDATA%\AgentCompany\prompts\` 也是全局的（不随 exe 走；没有该目录 = 用内置提示词，详见手册「自定义提示词」一节）。

**验证**：双击 `AgentCompany.exe` 出现主窗口（标题带 v1.1.1）；再双击第二次只会激活已有窗口（单实例）。

## 4b.（可选）安装终端命令 agentcompany

想在 PowerShell 里直接敲 `agentcompany` 开工：主程序 设置 → 可移植与自检 → **[安装终端命令]**——把 publish 根目录写入**用户 PATH**（不动系统 PATH）。

**验证**：**新开**一个 PowerShell 执行 `agentcompany --version`，输出「小公司 · Agent 指挥中心 · 终端版 v1.1.1」即成功（已在 PATH 的旧窗口不刷新，须新开）。注意：按钮写入的是**当前程序所在目录**——从 `publish\` 运行才会装上正式路径；终端模式与桌面版**互斥**（同一时刻只能开一个，后开的会被拒）。

## 5. 首次启动对照自检

1. **组织页**：三张员工卡都显示"自检：就绪"。
   - 有卡灰显"未安装"：按提示装 CLI（第 2 步）或到 设置 → 可移植与自检 填路径覆盖后[重新自检]。
2. **设置 → 可移植与自检**：六项全 `[OK]`——
   - claude / opencode / crush CLI
   - McpBridge（公司工具与审批门）
   - 工作区可写（显示解析出的工作区根，确认在预期位置）
   - SQLite 状态库
   异常项会在启动时弹一次提示；修好后[重新自检]即恢复派活。
3. **冒烟一单**：任务看板提一条小需求（如"写一个 hello.txt 内容为 你好"），CEO 拆解 → 确认开工 → 产物出现在 `workspace\pipeline\task-N\`。

**验证**：以上三步全过，部署完成。疑难对照《使用手册.md》FAQ。
