# R2 测试与验收手册 —— 手机可视化操作 CMD 命令行（Web 终端 ttyd）

> 迭代：R2『手机可视化操作 CMD 命令行（Web 终端 ttyd）』
> 本手册为两段式测试操作手册：阶段一在本机浏览器用手机模拟完成功能验证，阶段二在 iPhone 实机完成最终验证。
>
> 背景信息（与工作区实际产物一致）：
> - ttyd 由工作区内 `start-cmd.ps1` 启动，监听 `127.0.0.1:9801`；客户端 shell 为 pwsh 子进程，进入终端后自动执行 `[Console]::OutputEncoding=[System.Text.Encoding]::UTF8` 与 `chcp 65001`，保证中文输出无乱码。
> - Basic Auth 凭据存于同目录 `credentials.md`（格式为顶格的 `ttyd_user: <用户名>` 与 `ttyd_pass: <密码>`），由启动脚本自动解析，与 1.0 版本 UI 登录密码完全独立。
> - 停止服务运行 `stop-cmd.ps1`（读取并清理 `cmd.pid`，停止对应 ttyd 进程）；日志为 `cmd.out.log`（标准输出）与 `cmd.err.log`（错误）。
> - R1 中文门户页经 `tailscale serve` 挂在 8443 端口，R2 Web 终端子路径为 `/ttyd/`。
> - 1.0 基线（443→3000）只读不可动，任何操作不得影响其可用性。

---

## 阶段一：本机浏览器手机模拟验证

### 前置准备

1. 在工作区目录运行 `start-cmd.ps1` 启动 ttyd（若提示已在运行则直接进入下一步）。
2. 打开本机浏览器开发者工具（如 Edge/Chrome 按 F12），切换到手机模拟模式（设备仿真），任选一款 iPhone 机型。
3. 从 `credentials.md` 读取 Basic Auth 用户名（`ttyd_user:` 行）与密码（`ttyd_pass:` 行），后续登录时使用。

### 步骤 1-1：未带凭据访问返回 401

1. 在手机模拟浏览器中访问 `http://127.0.0.1:9801`。
2. 观察：先弹出 Basic Auth 认证框（要求输入用户名/密码）。
3. 点击「取消」或不输入凭据直接关闭认证框。
4. **预期结果**：页面返回 401 Unauthorized，不展示任何终端内容。

### 步骤 1-2：带凭据进入终端并验证中文输出

1. 再次访问 `http://127.0.0.1:9801`，在认证框中输入 `credentials.md` 中的用户名与密码。
2. **预期结果**：成功进入 Web 终端，看到 pwsh 提示符（进入时已自动执行 UTF-8 编码设置与 `chcp 65001`）。
3. 在终端中依次执行以下命令并观察输出：
   - `whoami` —— 预期输出当前 Windows 用户名，无乱码。
   - `dir` —— 预期输出当前目录文件列表，中文文件名/目录名（如有）显示正常，无乱码。
   - `ipconfig` —— 预期输出网络配置信息，中文字段（如「无线局域网适配器 WLAN」「IPv4 地址」等）显示正常，无乱码。
4. 若出现乱码，可在终端中手动执行 `chcp` 确认活动代码页为 65001，并检查 `cmd.err.log` 排查启动参数。

### 步骤 1-3：门户页「命令行终端」卡片跳转验证

1. 在手机模拟浏览器中访问 R1 中文门户页：`https://127.0.0.1:8443`（如证书告警可选择继续访问）。
2. 找到「命令行终端」卡片。
3. **预期结果**：点击卡片后跳转到 `/ttyd/` 子路径（经 tailscale serve 反代到本机 9801），弹出 Basic Auth 认证框；输入凭据后能进入终端（即 `/ttyd/` 可达且可用）。

### 阶段一收尾

阶段一全部通过后，可保持 ttyd 运行直接进入阶段二；如需重启服务，先运行 `stop-cmd.ps1` 再运行 `start-cmd.ps1`。

## 阶段二：iPhone 实机验证

### 前置准备

1. 确认电脑与 iPhone 已加入同一 Tailnet，且 `start-cmd.ps1` 已启动（ttyd 监听 127.0.0.1:9801）。
2. 确认 tailscale serve 已将 8443 端口的门户页与 `/ttyd/` 子路径正确代理。
3. 在 iPhone 上打开 Safari，准备好 `credentials.md` 中的 Basic Auth 用户名与密码。

### 步骤 2-1：未带凭据访问返回 401

1. 在 iPhone Safari 中访问 `https://<电脑名>.<tailnet>.ts.net:8443/ttyd/`（将 `<电脑名>.<tailnet>` 替换为实际 Tailnet 域名）。
2. 观察 Basic Auth 认证框，点击「取消」。
3. **预期结果**：返回 401 Unauthorized，不展示终端内容。

### 步骤 2-2：带凭据进入终端并验证中文输出

1. 再次访问 `https://<电脑名>.<tailnet>.ts.net:8443/ttyd/`，输入凭据登录。
2. **预期结果**：成功进入 Web 终端，看到 pwsh 提示符。
3. 依次执行并观察：
   - `whoami` —— 输出当前 Windows 用户名，无乱码。
   - `dir` —— 输出目录列表，中文名（如有）正常显示，无乱码。
   - `ipconfig` —— 中文字段（「无线局域网适配器 WLAN」「IPv4 地址」等）正常显示，无乱码。
4. 可额外输入一条含中文的命令（如 `echo 中文测试`）确认输入方向也无乱码（-W 已启用可交互写入）。

### 步骤 2-3：锁屏后会话存活验证

1. 保持终端页面处于打开状态，按下 iPhone 电源键锁屏。
2. 等待至少 30 秒（可更长，模拟日常锁屏时长）。
3. 解锁手机，回到 Safari 中的终端页面。
4. **预期结果**：终端会话仍然存活——之前的输出内容仍在，提示符可继续输入；再次执行 `whoami` 能正常返回，无需重新认证、无需刷新页面。
5. 若会话断开，检查 tailscale serve 反代与 ttyd 的连接超时设置，排查后重测。

### 阶段二收尾

全部验证完成后，如不再需要终端服务，运行 `stop-cmd.ps1` 停止 ttyd；如需长期使用可保持运行。
