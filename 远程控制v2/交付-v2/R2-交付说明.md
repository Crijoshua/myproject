## 宿主侧部署事实

- ttyd：`127.0.0.1:9801`，`-c` Basic Auth，`-W` 可交互；客户端 shell 回退 Windows PowerShell 5.1（本机无 pwsh），进入终端自动执行 UTF-8 初始化（OutputEncoding + chcp 65001）。
- **ttyd 网关（9802）**：阶段二实测发现 **iOS Safari 不在 WebSocket 升级请求上携带 Basic Auth 凭据**（Chrome 会带），ttyd `-c` 在 HTTP 层即拒绝（日志 `User code denied connection`）→ 新增零依赖 node 网关 `ws-gateway.js`：普通请求校验 Basic（401 语义不变）并签发 12h 会话 Cookie；WS 升级接受 Cookie 或 Basic 任一凭证，向 ttyd 注入 Authorization 后桥接。start/stop-cmd.ps1 已联动管理（gateway.pid）。
- **ttyd 不带 `-b` base-path**：实测 tailscale serve 子路径反代会剥掉 `/ttyd` 前缀转发，带了 `-b` 反而 404。
- Serve：`tailscale serve --bg --https=8443 --set-path=/ttyd 9802`（网关），443 基线通道未动。
- policy file：无需变更（R1 已追加 `tcp:8443, tcp:10000` grant）。
- 启停脚本已加 UTF-8 BOM（PS 5.1 兼容，与 R1 add-bom.ps1 同因）。
