# 安装与运行

## 一、还原 / 安装 Crush 插件

插件需要放回 Crush 的技能目录才能生效：

```powershell
# 1. 把插件复制到 Crush 技能目录（Windows 下）
Copy-Item -Path "仓库根目录\apo-optimizer" -Destination "$HOME\.config\crush\skills\" -Recurse

# 2. 重启 Crush，然后对它说：
#    "跑一下 APO"  或  "优化提示词"
```

**重要**：插件的 `run_apo.py` 按约定查找 `~/apo/apo_loop.py`，
所以引擎必须放在**用户主目录的 `apo/` 文件夹**里：

```powershell
Copy-Item -Path "仓库根目录\apo" -Destination "$HOME\apo" -Recurse
```

如果不想把引擎放在主目录，需要自行修改 `apo-optimizer/scripts/run_apo.py` 中的
`apo_script_path` 和 `log_dir` 两个路径。

## 二、手动运行引擎（不经 Crush）

```powershell
# 1. 安装依赖
pip install -r requirements.txt

# 2. 设置智谱 API Key（必需，否则脚本启动即退出）
$env:ZHIPU_API_KEY = "你的key"

# 3. 运行引擎（基于脚本自身位置定位文件，在任意目录下执行均可）
python apo/apo_loop.py
```

运行完 1-3 分钟后查看结果：

- `apo/best_prompt.md` —— 优化后的最佳提示词
- `apo/logs/round_*.log` —— 每轮的提示词、平均分、各任务得分
- 控制台最终会打印留出集（holdout）验收报告

## 三、依赖清单

| 依赖 | 用途 |
|---|---|
| Python 3.8+ | 运行环境（提示词本身也要求兼容 3.8+） |
| `openai`（PyPI 包，见 `requirements.txt`） | 调用智谱 OpenAI 兼容接口 |
| `pyyaml` | 读取 config / 任务集 / 验收标准 |
| 智谱 API Key | 环境变量 `ZHIPU_API_KEY` |

LLM 端点与模型**硬编码**在 `apo/apo_loop.py` 顶部：

```python
client = OpenAI(api_key=API_KEY, base_url="https://open.bigmodel.cn/api/paas/v4/")
MODEL_NAME = "GLM-5.3-Flash"
```

换模型要直接改代码，不在配置文件里。
